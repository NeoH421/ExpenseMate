# مصروفي — ExpenseMate

تطبيق شخصي عربي لتسجيل الدخل والمصروف بالدولار والليرة السورية، مع آلة حاسبة جانبية وسعر صرف قابل للتعديل.

## المزايا
- واجهة عربية RTL حديثة.
- دخل / مصروف / تحويلات داخلية.
- عملة USD و SYP.
- سعر صرف قابل للتعديل من الإعدادات.
- ملخص الرصيد والإجمالي الشهري.
- سجل العمليات مع وصف وتاريخ.
- حذف عملية بالضغط المطوّل.
- آلة حاسبة صغيرة من الزر العائم أعلى الشاشة.
- حفظ محلي على الهاتف باستخدام SharedPreferences.
- لا يحتاج إنترنت ولا حساب.

## البناء
افتح المشروع في Android Studio ثم Build > Build APK(s). المشروع يستخدم Android Gradle Plugin 8.7.3 وcompileSdk 35.
